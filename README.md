## 打开与使用

预览可直接双击 `dist/index.html`，无需安装依赖。真实登记需配置Supabase并通过托管HTTPS页面打开；离线文件始终只作预览。`dist/standalone.html` 将样式、插画与脚本全部内嵌，可以单独复制或离线打开。也可用静态HTTP服务器打开dist目录。右上角滑杆图标打开研究者面板；URL增加 `?studio=1` 可直接进入该面板。

默认预算600 PKR、替代品在视线层、原价、四项营养灯加UPF灯开启。三个陈列区均固定四层，各区宽度按商品数量确定，每SKU两个陈列面；支持左右按钮、位置滑条、鼠标拖拽、键盘和手机横向滑动。价格改为仅对NOVA4加价20%、25%或30%。可以独立切换陈列方式、价格和标签，或随机预览八种组合。随机按钮仅供演示，不是正式研究的隐蔽分配。切换条件会保留上一段本地记录并开启新的空购物篮。

可以选择不购买；确认结账的空篮与尚未结账分开记录。结账后显示购买能量与UPF能量；含未判定食品或零能量购物篮不显示虚假的UPF占比。没有健康得分、排行榜、真实支付或兑现承诺。

## 五项交通灯：演示规则

所有商品图像均为程序绘制的示意插画，营养、价格及NOVA字段均为合成测试数据，不能引用为真实商品数据。

| 指标 | 绿色 | 黄色 | 红色 |
|---|---|---|---|
| 能量：食物 kcal/100g | ≤150 | >150且≤300 | >300 |
| 能量：饮料 kcal/100ml | ≤20 | >20且≤40 | >40 |
| 总脂肪：食物 g/100g | ≤3 | >3且≤17.5 | >17.5 |

| 总糖：饮料 g/100ml | ≤2.5 | >2.5且≤11.25 | >11.25 |
| 盐：食物 g/100g | ≤0.3 | >0.3且≤1.5 | >1.5 |
| 盐：饮料 g/100ml | ≤0.3 | >0.3且≤0.75 | >0.75 |
| UPF/加工等级 | NOVA 1 | NOVA 2/3 | NOVA 4 |

未知NOVA显示灰灯。NOVA不是按营养分数计算；如原味坚果可以是加工绿灯但脂肪红灯。能量阈值与UPF颜色为本原型的自设映射，待Delphi审议，并非官方标准。营养阈值简化参考英国2016指南的每100g/ml规则，尚未实现全部份量例外和饱和脂肪指标。英国该方案本身不为能量信息设置红黄绿。

来源与边界：

- UK front-of-pack technical guidance: https://assets.publishing.service.gov.uk/media/5a80cd03ed915d74e33fc7c5/FoP_Nutrition_labelling_UK_guidance.pdf
- NOVA参考（不是官方颜色定义）：https://www.fao.org/4/ca5644en/ca5644en.pdf

正式研究前，必须审核商品和全部分级规则、确认标签条件是“营养+UPF”的组合信息效果，并完成本版三语文案的当地审校、相关伦理材料与方案冻结。既有研究材料不在此任务中自动改写。

## 数据与隐私

默认预览模式只记录浏览器内的购物体验，不发送验证码或个人资料。最多保留20段历史、每段800事件；预览登记表中的出生日期、性别、学校、身体测量和问卷编号不进入本地购物存储或导出。

已准备Supabase接入：联系方式由Auth处理，完整出生日期、性别、学校、身高(cm)、体重(kg)、腰围(cm)、选填问卷编号和随机参与者编号保存在有访问限制的资料表。前端按出生日期计算年龄，不收集姓名。新研究的购物篮自动保存到服务器，并按参与者恢复；未送达的最后更改仍需等待保存。历史固定条件试用的未提交购物篮仍只在内存。认证令牌保存在当前标签页sessionStorage，退出清空令牌及页面记录。扫码只打开参与入口，之后仍需验证码验证。

服务端校验登记年龄18—26岁、联系方式验证状态与参与说明版本；学生只能读取自己的资料，不能直接改写资料、研究条件或访问他人购物表。结账只上传商品ID和数量等必要字段，服务端重算价格与预算并保证重试不重复提交。STUDY_ID为空时仍为历史固定条件试用；设置新STUDY_ID并部署006后由服务器随机分配，研究首次分配后冻结定义。

**目前没有真实Supabase项目，验证码送达与线上数据库联调尚未完成。** 通过[部署指南](DEPLOY_GITHUB.md)配置后启用。最终GitHub Pages页面可公开访问，无需ChatGPT或GitHub账号。原有Sites链接未在本轮更新。

# Campus Shelf · 校园虚拟货架

这是可以直接打开的网页购物原型，包含15个合成示例商品、中文/英文切换、分类与搜索、购物篮、预算限制、商品详情、结账回执、研究者条件面板及本地JSON导出。

## 打开与使用

直接双击 `dist/index.html` 即可，无需安装依赖。`dist/standalone.html` 将样式、插画与脚本全部内嵌，可以单独复制或离线打开。也可用静态HTTP服务器打开dist目录。右上角滑杆图标打开研究者面板；URL增加 `?studio=1` 可直接进入该面板。

默认预算600 PKR，常规价格与顺序，四项营养灯加UPF灯开启。可以手动切换价格、位置和标签，或随机体验八种组合中的一种。随机按钮仅供演示，不是正式研究的隐蔽分配。切换条件会保留上一段本地记录并开启新的空购物篮。

可以选择不购买；确认结账的空篮与尚未结账分开记录。结账后显示购买能量与UPF能量；含未判定食品或零能量购物篮不显示虚假的UPF占比。没有健康得分、排行榜、真实支付或兑现承诺。

## 五项交通灯：演示规则

所有商品图像均为程序绘制的示意插画，营养、价格及NOVA字段均为合成测试数据，不能引用为真实商品数据。

| 指标 | 绿色 | 黄色 | 红色 |
|---|---|---|---|
| 能量：食物 kcal/100g | ≤150 | >150且≤300 | >300 |
| 能量：饮料 kcal/100ml | ≤20 | >20且≤40 | >40 |
| 总脂肪：食物 g/100g | ≤3 | >3且≤17.5 | >17.5 |
| 总脂肪：饮料 g/100ml | ≤1.5 | >1.5且≤8.75 | >8.75 |
| 总糖：食物 g/100g | ≤5 | >5且≤22.5 | >22.5 |
| 总糖：饮料 g/100ml | ≤2.5 | >2.5且≤11.25 | >11.25 |
| 盐：食物 g/100g | ≤0.3 | >0.3且≤1.5 | >1.5 |
| 盐：饮料 g/100ml | ≤0.3 | >0.3且≤0.75 | >0.75 |
| UPF/加工等级 | NOVA 1 | NOVA 2/3 | NOVA 4 |

未知NOVA显示灰灯。NOVA不是按营养分数计算；如原味坚果可以是加工绿灯但脂肪红灯。能量阈值与UPF颜色为本原型的自设映射，待Delphi审议，并非官方标准。营养阈值简化参考英国2016指南的每100g/ml规则，尚未实现全部份量例外和饱和脂肪指标。英国该方案本身不为能量信息设置红黄绿。

来源与边界：

- UK front-of-pack technical guidance: https://assets.publishing.service.gov.uk/media/5a80cd03ed915d74e33fc7c5/FoP_Nutrition_labelling_UK_guidance.pdf
- NOVA参考（不是官方颜色定义）：https://www.fao.org/4/ca5644en/ca5644en.pdf

正式研究前，必须审核商品和全部分级规则、确认标签条件是“营养+UPF”的组合信息效果，并完成Urdu适配、伦理与方案冻结。既有研究材料不在此任务中自动改写。

## 数据与隐私

本应用没有研究后端、身份采集、付款或外部数据分析脚本。体验记录保存在当前浏览器localStorage，含体验条件、浏览到的商品、加减数量、帮助查看、结账和时间信息。记录不是正式受试者数据。页面不会将其提交给研究服务器；导出按钮创建本地JSON。

最多保留20段历史体验，每段最多800个事件；超出后滚动保留最近记录。本地存储不可用时提示并改用内存；结束页面前需导出。不收集真实姓名、联系信息、摄像头或麦克风信息。公开页面的研究者开关不是安全边界，因此本版不能用于正式盲法随机化。

## 代码与检查

- `dist/data.js`：合成商品库。
- `dist/core.js`：分级、价格、预算、排序与结果计算。
- `dist/app.js`：购物流程、弹窗、条件、语言及本地记录。
- `dist/styles.css`：桌面与移动布局。
- `tests/core.test.cjs`：预算、八种条件、营养/NOVA独立性、未知分类、零能量及结果快照测试。

使用Node 18+：`node --test tests/core.test.cjs`。代码不依赖npm安装。部署目录为dist，Sites身份配置在 `.openai/hosting.json`。
